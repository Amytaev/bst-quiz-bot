# Telegram Quiz Bot — БСТ

## Установка

```bash
pip install python-telegram-bot
```

## Настройка

1. Создай бота через @BotFather → получи токен
2. Вставь токен в bot.py строка: `TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"`
3. Положи `bot.py` и `questions.json` в одну папку

## Запуск

```bash
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню с выбором режима |
| `/stop`  | Остановить текущий квиз |
| `/score` | Текущий счёт |

## Режимы

- **Экзамен** — 20 случайных вопросов, 30 сек на каждый (как на реальном экзамене)
- **Полный квиз** — все 500 вопросов
- **По теме** — 15 тем на выбор
- **Случайные 50** — быстрая тренировка

## Темы квиза

1. Модель OSI/TCP-IP и атаки L2-L4 (вопросы 1-33)
2. VPN и IPsec (34-67)
3. SSH, FTP, Brute Force (68-100)
4. Wireshark и анализ трафика (101-133)
5. Файрвол и iptables (134-166)
6. IDS/IPS — Snort, Suricata (167-200)
7. SIEM, SOC, ELK Stack (201-232)
8. DDoS и ботнеты (233-266)
9. Wi-Fi безопасность (267-300)
10. TLS/PKI и криптография (301-334)
11. DNS и безопасность DNS (335-367)
12. Реагирование на инциденты (368-400)
13. Sandbox и анализ malware (401-433)
14. Email безопасность (434-466)
15. Пентест и инструменты (467-500)
